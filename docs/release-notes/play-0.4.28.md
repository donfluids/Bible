# Google Play release: 0.4.28 (build 55)

For the English app (Bible) and the Malayalam app (വേദപുസ്തകം). The last release on
Play was build 45 (0.4.18), so these notes cover 0.4.19 to 0.4.28.

In Play Console, open the release (Testing or Production → Create new release), upload
the bundle, and paste the release name and the release notes below. Each language's text
sits between its tags, and Play allows 500 characters per language. The texts below are
455 characters (English app), 437 (Malayalam app, Malayalam) and 471 (Malayalam app,
English).

## English app (org.riversresearch.bible)

Bundle: `Bible-0.4.28-b55.aab` from the `apk-builds` branch.

Release name:

```
55 (0.4.28)
```

Release notes:

```
<en-US>
• Cross references and parallel passages for every verse
• About this book: an introduction to each book
• Read aloud in a voice you choose in Settings
• Simpler reader: tap the title for a passage or Bible, swipe for chapters
• Books tab: all 66 books at once, and recent chapters
• Notebook: backup, PDF, search, and the text of a verse you type
• Handwritten pages zoom with two fingers
• New verse card designs
• How to use and Write to us in Settings
</en-US>
```
